# 图像服务（DFL-WEBUI 源码功能）

“工具实验室 → 图像工具”使用奇智图像 API，提供文生图、提示词图像编辑、清晰度增强与参考图合成。增强及参考图合成是提示词预设，可以自行修改；服务不保证像素级还原或身份一致性。参考图合成不调用本地 DFL 检查点；现有 SAEHD/AMP 等 DFL 合成及 FaceEnhancer 仍通过原有工具执行。奇智模块不改变本项目原有 TensorFlow、SAEHD 训练架构或本地运行时。

## 配置与使用

1. 点击“申请 API”，打开用户指定的[奇智注册页面](https://api.qizhi.cc/sign-up?aff=Vwf1)，在该平台的令牌设置中取得自己的 Key。
2. 在图像工具中填写 Key 并保存。服务地址固定为 `https://api.qizhi.cc`，默认模型为 `qizhi-image-g-v2.5-lowprice`。
3. 文生图填写提示词即可。编辑、增强及参考图合成需要选择图片；可从当前 aligned 素材导入，也可选择本机 JPG、JPEG、PNG、WEBP。
4. 选择宽高比、分辨率和提示词，查看提交确认。确认框列出服务商及本次有序素材范围；确认后才向奇智上传素材并提交任务。
5. 页面显示任务进度，结果自动保存到当前项目，可预览或下载。切换页面不取消后台任务；有任务号时，检查进度只查询原任务并尝试保存结果，不重新生成。

图片选择仅在本机暂存。奇智[素材规则](https://api.qizhi.cc/docs/#materials)要求公开图片链接，不支持内嵌 Base64；WebUI 确认后使用官方[上传接口](https://api.qizhi.cc/docs/#upload)获得临时链接，再按所选顺序提交。单张图片上限 50 MB，一次最多 15 张参考图，生成数量固定为 1。

已有链接输入只接受公开 HTTPS 地址；本机、私有网络、含账号密码或需要登录的链接不能作为参考素材。本机图片先按顺序提交，再提交已有链接；两组内均可调整顺序。

## Key 和文件

Key 由本机服务端管理，不存浏览器 localStorage，不在配置读取响应中回传。Windows 使用当前系统用户的 DPAPI 加密保存在 `webui/.runtime/image-service/settings.json`；切换 DFL 项目共用该配置。其他系统只保留本次服务会话的 Key。Key 留空保存时沿用已有配置，也可明确清除。

项目输入副本、任务记录和生成图片位于该项目的 `.webui/image-service`，不覆盖 aligned 原图，不自动加入训练集，不写入 DFL 标注。该目录与全局配置目录均从 Git 和发行包中排除。任务历史保存提示词、素材、模型、尺寸、任务号及结算信息，便于继续检查或追溯。

## 状态、计费与能力范围

提交使用官方[生成接口](https://api.qizhi.cc/docs/#create-image)，随后按[任务状态接口](https://api.qizhi.cc/docs/#get-image)每 3 秒查询。兼容正式状态 `NOT_START`、`SUBMITTED`、`IN_PROGRESS`、`SUCCESS`、`FAILURE` 及 `completed`、`failed` 等写法。轮询有时间上限；暂停检查保留任务号，之后可以继续查询。

收费提交不自动重试。提交期间断线且未获得任务号时，记录“结果未确认”，需先在平台检查，避免重复扣费。已成功的任务下载失败时保留任务号，继续检查会重新尝试保存同一结果。平台临时结果链接约 24 小时后失效，WebUI 会尽快下载，但没有跨越有效期的恢复保证。

只显示服务最终返回的 `data.usage.amount` 和 `currency`；未返回时不猜测费用，也不显示为 0。失败任务只有服务实际返回退款结算为 0 时才显示 0。最终费用、上游模型版本及可用性由平台决定。

当前模型的[公开规则](https://api.qizhi.cc/docs/#image-g-v25-ext)提供提示词、多图参考、宽高比、1k/2k/4k 分辨率和可选内容检查，没有公开遮罩、编辑强度、输出格式、透明背景或流式参数。界面不宣称精确局部重绘，也不把这项图像 API 视为视频关键帧传播能力。

本轮通过 38 项离线检查（21 项图像管理、6 项本地接口、7 项网络与代理兼容、4 项素材上下文检查），完成原版前端构建及构建来源核验，并检查 Windows DPAPI 加密/解密往返。共用图像模块在 DFL-PT-WEBUI 中用授权 Key 对人工几何图执行了一次真实编辑：默认模型、1:1、1k、生成数量 1；素材上传、任务提交、状态查询、图片下载与本地附件接口均通过。原版 DFL-WEBUI 使用自己的服务和隔离测试目录，从该任务号恢复查询并重新下载结果，本地附件的文件散列一致，没有再次提交收费生成。红色圆形按提示变为蓝色，其余图形保留；这不构成人脸、视频或精确局部重绘的质量验收。平台成功响应暂未提供最终 usage，因此本次费用显示为未结算，不推算扣费。不启动训练或 GPU 验收。

本机代理将域名解析为 198.18/15 合成地址时，图片服务使用固定可信 HTTPS DNS 查询真实公开地址；仍检查公开 IP、固定连接地址并验证原域名 TLS。普通私网及混合公开/私网解析继续拒绝，DNS 查询不发送 API Key。
